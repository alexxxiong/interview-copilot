# 个人资料模板

填写后粘贴到应用「个人经历」。这些字段不代表任何人的实际经历，没有的信息留空。提问时资料可能作为上下文发送给所选模型，请自行决定填写范围。

## 基本背景

- 目标岗位：
- 技术方向与工作年限：
- 任职经历（公司、时间、正式岗位）：
- 下一阶段希望解决的问题：

## 项目通用结构

- 谁使用这个系统，要完成什么任务：
- 原流程卡在哪里，造成什么影响：
- 本人负责哪些决策、模块或交付：
- 其他成员负责什么：
- 采用什么方案，为什么放弃其他方案：
- 结果及证据（基线、环境、工作量、统计口径）：
- 一次真实失败、修正或未解决的问题：

以下标题可以关联卡片中的「我的相关经历原文」，未做过的项目直接删除。不使用这些标题时，资料仍会作为 Agent 上下文。

## AI 运维与 MCP

按通用结构填写，区分标准化、自动化和 AI 入口各自的收益。

## 知识库问答

说明数据、检索、生成、微调与评测中的本人职责，区分检索命中与回答正确。

## 协程与订单管理

说明运行时、状态机、并发边界和异常恢复，区分代码简化与性能收益。

## 回测与 SDK

说明任务定义、数据规模、并发度、基准环境、正确性检查与优化前后结果。

## 多租户与任务托管

说明租户信任关系、身份和资源隔离、控制面职责与故障恢复验证。

## 低延迟项目

说明时间戳起止点、硬件、分位数、负载与本人参与部分；团队使用某技术不等于本人实现全部组件。

- 已确认到岗日期（未确认留空）：
